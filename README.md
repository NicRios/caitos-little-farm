# Caito’s Little Farm

A responsive, single-page farm website inspired by an airy editorial travel layout. All photography is represented by local SVG placeholders so the finished photos can be swapped in without changing the page structure.

## Run locally

```bash
npm install
npm run dev
```

## Replace the placeholders

The temporary art lives in `public/placeholders/`. Keep the filenames and replace each SVG with a final image using the same aspect ratio, or update the matching `src` in `app/page.tsx`.

Before sharing publicly, replace `hello@example.com`, the visit note, and the address placeholder in `app/page.tsx`.
